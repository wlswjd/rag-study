Dense의 약점을 정확히 보완하는 방식이 있습니다. Sparse Retrieval(희소 검색)입니다.
>Sparse Retrieval:
  텍스트 → 단어별 가중치(대부분 0인 거대한 벡터) → 키워드 매칭
  "단어"를 비교한다
대표적인 알고리즘이 BM25입니다. Google 같은 전통적인 검색 엔진의 근간이 된 방식입니다.
이름이 "Sparse"인 이유는 벡터의 대부분이 0이기 때문입니다.
어휘 사전이 10,000 단어라고 하면:
"강아지 사료"라는 텍스트의 Sparse 벡터:
  [0, 0, 0, ..., 0, 1.5(강아지), 0, ..., 0, 2.1(사료), 0, ...]
10,000차원 중 단 2개만 0이 아님

따라서, Hybrid Search: Dense 검색 결과 + Sparse 검색 결과 → 점수 결합 → 최종 순위

---
BM25 이전에는 이런 식으로 점수를 매겼습니다.
>Term Frequency (TF) — 단어 빈도수
질문: "강아지 사료"
문서 A: "강아지 사료를 추천합니다"           → "강아지" 1번, "사료" 1번 → 점수 2
문서 B: "강아지 강아지 강아지 사료 사료"      → "강아지" 3번, "사료" 2번 → 점수 5
TF만 보면 문서 B가 더 좋은 결과
>>이걸 수치화한 게 IDF입니다.
IDF(단어) = log(전체 문서 수 / 그 단어가 나온 문서 수)
예시: 전체 1000개 문서 중에서
  "그"가 들어간 문서: 950개
  IDF("그") = log(1000 / 950) = log(1.05) ≈ 0.05  → 매우 낮음
  "글루코사민"이 들어간 문서: 5개
  IDF("글루코사민") = log(1000 / 5) = log(200) ≈ 5.3  → 매우 높음

---
1. BM25의 첫 번째 트릭 — TF에 천장(saturation)을 둔다
TF가 1 → 점수 1.0
TF가 5 → 점수 1.5
TF가 10 → 점수 1.7
TF가 50 → 점수 1.9
TF가 1000 → 점수 1.99
→ 어느 시점부터 점수가 거의 안 올라감 (수렴함)
이걸 제어하는 파라미터가 k1입니다 (보통 1.2~2.0).

2. BM25의 두 번째 트릭 — 문서 길이를 정규화한다
이걸 제어하는 파라미터가 b입니다 (보통 0.75).
b = 0    → 길이 정규화 없음 (TF-IDF와 동일)
b = 1    → 길이 정규화 최대
b = 0.75 → 적당히 절충 (대부분의 경우 무난)

=> BM25는 단어 희귀도(IDF) × 빈도(TF, 단 천장 있음) × 문서 길이 보정으로 점수를 매기는 키워드 검색 알고리즘입니다. 핵심 파라미터는 **k1(빈도 반영 강도)**와 **b(길이 정규화 강도)**이고, 기본값(k1=1.5, b=0.75)으로 거의 모든 경우 잘 작동합니다. 학습이 필요 없어서 가볍고, 고유명사/정확한 단어 매칭에 강합니다. 동의어/의역에는 약해서 Dense 검색과 보완 관계입니다.

4. RRF 공식
이름 그대로입니다. Reciprocal(역수), Rank(순위), Fusion(결합).
RRF 점수 = Σ ( 1 / (k + 순위) )

각 검색에서 그 문서가 받은 순위의 역수를 모두 더함
```
k는 상수 (보통 60)
k가 작으면 (예: k=1):
  1위 → 1/2 = 0.5
  2위 → 1/3 ≈ 0.33
  → 1등 효과가 너무 큼. 한 검색의 1등이 다른 검색을 압도
k가 크면 (예: k=1000):
  1위 → 1/1001
  100위 → 1/1100
  → 순위 간 차이가 거의 없어짐. 합치는 의미 약해짐
k=60은 둘 사이의 균형점
```

RRF의 장점
```
1. 점수 척도 무관
   Dense의 0~1, BM25의 0~30, 어떤 점수 체계든 상관없음
   → 다른 검색 시스템(BM25 외 ColBERT 등)과도 쉽게 결합

2. 이상치에 강함
   특이하게 높은 점수가 있어도 순위 1위로 처리될 뿐
   다른 결과를 묻어버리지 않음

3. 파라미터 거의 없음
   k 하나, 그것도 60 고정으로 거의 다 됨
   → 튜닝 부담 없음

4. 구현이 간단
   몇 줄짜리 코드로 끝남

5. 여러 검색 결과 합치기 가능
   Dense + BM25뿐 아니라 3개, 4개도 같은 방식으로 합칠 수 있음
   예: Dense + BM25 + Re-rank + Filter
```

Dense 검색은 의미에 강하고, BM25는 정확한 단어에 강하다. 둘을 RRF로 합치면 서로의 약점을 보완한다. 한국어에서 BM25는 형태소 분석이 필수다.
